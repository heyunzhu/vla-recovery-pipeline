# libero90_legacy Skill Pack

This pack mirrors the historical LIBERO-90 recovery skill library.

Use it when reproducing or extending the LIBERO-90 line:

```bash
python -m experiments.robot.libero.skill_pipeline.runner \
  --enable_skills \
  --skill_pack libero90_legacy
```

The old `skills/_index.yaml` entrypoint remains available for compatibility.
