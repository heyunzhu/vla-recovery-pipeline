# 起点交叠与运动新增交叠（2026-10-07）

## 本次完成

增加当前点云在机器人各部件中的交叠集合比较。基准为 observation 的实际当前关节角，涵盖8个手臂部件和5个夹爪collision部件。当前姿态的深度一致性自身像素证据固定使用，不能用未来姿态生成遮罩删除环境点。

交叠键为“部件ID＋当前帧像素ID”。每个姿态分别记录：相对起点新增、起点已有且仍存在、起点已有但该姿态已不交叠。同一像素从一个部件进入另一个部件，仍计为新增配对；原有交叠没有被忽略，也没有滚动更新基准。

在原40个IK位置之间做关节线性插值，相邻检查姿态的最大单关节变化不超过0.01rad；重复关节位置跳过，最终生成95个检查姿态。插值保持静态限位，但不保证中间EEF按原笛卡尔直线走，更不等于连续碰撞检查或时间参数化。
