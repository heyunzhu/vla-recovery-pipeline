# 夹持垫间隙的 RGB-D 观测检查

日期：2026-10-07。范围：可见夹持区域的射线覆盖，尚未生成 HandEmpty / Holding 初始事实。

## 方法

从已校验的静态 Panda XML 和碰撞几何取得当前两个 pad 的位置。关节角只来自允许的机器人 proprioception。在 hand 坐标系下，用两垫内侧面及其共用 X/Z 范围建立间隙盒，Y 边界向内留 1mm。算法逐一计算所有与盒相交的图像像素中心射线的入/出盒光学深度。

只有有效深度在出盒深度后超过2mm的射线计为可见自由。盒前表面遮挡计为未知；盒内/边界深度、无效深度、部分盒出画面及不足16条射线都不能判为可见自由。不会先剔除机器人点再将遮挡解释为空间自由。

这能检查当前分辨率下垫面间隙的深度覆盖，不能证明所有可能附着物、亚像素/透明物体或完整持物状态。因此输出 hand_state 仍 unknown，initial_atoms 为空，无执行许可。后续需将这种局部几何证据与明确的夹持模型和时间证据组合，并验证真实误判率。
