# 剩余点归因与夹爪/手臂粗检（2026-10-07）

## 本次推进

在既有全臂自身像素证据上，增加两个独立诊断：

1. 对**当前 proprio 姿态**剩余的外包体交叠点，计算它们距实际 collision STL 三角表面的最短距离，并用两条通用方向射线检查奇偶性。先核对精确顶点边拓扑：每条边出现两次、无退化面；开放边或射线命中共享边时保留 unknown。
2. 沿原有40个IK解更新夹爪完整位姿，固定当前开合值，检查5个夹爪collision部件与link0—link6的35组面轴配对。直接连接的link7明确排除；不是完整机器人自碰撞检查。

输入仍为历史 RGB-D、proprio、静态机器人模型和已保存规划轨迹。没有读取物体真值，没有新环境动作或 GPU 任务。
