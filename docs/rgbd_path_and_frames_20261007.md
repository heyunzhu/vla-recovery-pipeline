## 路径检查的范围

本轮使用声明半径40mm的末端球代理，沿各位置段每10mm采样。每个中心及六个轴向表面位置投影到当前 RGB-D，相对观测深度保留5mm margin；视野外、无有效深度、靠近或在已见表面后方的探测点保留为未知/不支持。

另对所有可见点计算至球中心距离，报告球内是否存在观测点。没有过滤目标或机器人点，也没有将空点群或缺失深度判断为自由空间。

此球只是诊断代理，未由完整机械臂/夹爪 mesh 推导；七个位置探测点和离散中心不是连续扫掠体。没有自碰撞、完整机械臂碰撞或关节IK验证。
